图片目录结构

按年份与月份保存

每张壁纸使用 YYYY-MM-DD.jpg 作为文件名， 便于根据日期构造图片地址。

images/
└── 2026/
    └── 10/
        └── 2026-10-08.jpg

图片 URL 规则

将日期替换为目标壁纸日期，即可构造对应的高清图片地址。 访问前需确认该日期的图片确实存在。

https://bing-uhd.伴随.cn/images/YYYY/MM/YYYY-MM-DD.jpg

仓库职责

本仓库只负责 UHD 图片文件，不保存月度 JSON、 preview、Base64 或颜色直方图数据。

数据与前端

壁纸网站从 bing-data 读取元数据与预览图， 在需要查看高清图或下载时再访问本仓库。

数据：https://bing-data.伴随.cn/
前端：https://bing.伴随.cn/

📐 图片规格

常见尺寸 3840×2160 (16:9)，JPEG 格式。 个别日期可能因源尺寸不同而略有差异，以实际文件为准。

🔄 自动更新流程

由 bing-data 的 GitHub Actions 每日抓取、下载 UHD 图片并推送至本仓库，确保图片持续更新。

bing-data workflow → 下载 → 提交到 bing-uhd
